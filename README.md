## How to Compile and Run

1. Install Java JDK.
2. Open PowerShell in the project folder.
3. Compile the required program:

```bash
javac Q1/Q1.java
```

4. Run the program:

```bash
java -cp Q1 Q1
```

Replace Q1 with the required class name for other programs.
